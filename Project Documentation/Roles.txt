Team roles:

Backend Technical lead:

 - ensures code quality
 - ensures correct level of code separation and readability
 - ensures file system remains intact and code is structured appropriately

Frontend Technical lead:
 - enforces chosen development style 
 - enforces version control etiquette
 - ensures code quality
 - ensures correct level of code separation and readability

Documentation manager:

Devops manager:

UI design manager:

Compliance manager:

Development roles:
    there are a few ways I think development can be decomposed,
    via frontend/Backend:
        this works well as people with differening skill sets can spend more time implementing them usefully e.g: functional JS v Python 
        language experience, however because we will be trying to switch roles and make sure everyone has baseline knowledge of the system
        these roles will be rotated a few times.
    via full stack slice:
        this means that 1 or 2 people will work on each feature from backend to frontend - they will make the webpages, make the api end points 
        and code the business logic for 1 particular feature. this means slightly less reliance on others code, and slightly easier in terms of
        orchestrating handoffs e.g: the backend waiting for the frontend telling them what data they need at each API endpoints. however because
        it's easier it may mean the code becomes very different and hard for one person to switch between working on one feature to working on another
    Via a bit of both:
        we could firmly split people off into 3 pairs and one solo where each pair works on one feature, one on frontend, one on backend, 
        this technique could work very well, but requires good comms between pairs on the same feature, but it would speed up the acclimatisation process
        if we only swapped one person from a pair at a time - meaning at least one person always has experience of the feature and can work with the other.
        A problem with this is that both members of the pair would need to be coding in sync and communicating well otherwise it falls apart.
