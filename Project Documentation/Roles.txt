Team Lead:

Backend Technical lead:
 - enforces test driven development (or whatever style we want to do)
 - enforces version control etiquette
 - ensures code quality
 - ensures correct level of code separation and readability

Frontend Technical lead:
 - enforces chosen development style 
 - enforces version control etiquette
 - ensures code quality
 - ensures correct level of code separation and readability
